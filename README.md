# スギスギてまこ（推し熱量リズムゲーム）

好きな音楽ファイルを読み込んで遊べる、ブラウザだけで完結するリズムゲームです。
上から降ってくるノーツを、対応するレーンをタップ（またはキーボード）してタイミングよく叩き、推し熱量ゲージを溜めよう。

## 遊び方

1. `npm run dev` でローカルサーバーを起動し、ブラウザで開く
2. スタート画面で音楽ファイル（mp3 / m4a / wav / aac / ogg）を選択
3. 曲の BPM（テンポ）と難易度（EASY / NORMAL / HARD）を設定
4. 「スタート」を押して、降ってくるノーツが判定ラインに重なったタイミングでレーンをタップ
5. 熱量ゲージが 100% に到達すると「LIMIT BREAK」演出が発生し、スコア倍率が上昇

## 操作方法

| 環境 | 操作 |
|---|---|
| スマホ・タブレット | ノーツが降ってくるレーン（上下左右）をタップ |
| PC（Mac 含む） | 矢印キー（&uarr;&darr;&larr;&rarr;）または `W`/`A`/`S`/`D` |

PC で画面サイズが広い場合は、スマホ風の縦長カードが中央に表示されます。

## 開発環境のセットアップ

Node.js は不要です。Python 3 標準の簡易サーバーのみ使用します。

```bash
npm run dev
```

`http://localhost:5500` が起動します（`python3 -m http.server` のラッパーです）。
`file://` で直接 `index.html` を開いても動作しますが、ブラウザによっては
音声ファイルの読み込みに制限がかかることがあるため、ローカルサーバー経由を推奨します。

## 現在の仕様

- **譜面生成**: 指定 BPM をベースに、音楽的なパターン（階段／左右交互／2連ずつ／軸押しなど9種）を
  2回ずつ繰り返しながら並べる方式。ランダム方向ではないので手がパターンを覚えられる。
  難易度ごとの確率で休符が入り、一本調子になるのを防いでいる（実音源のビート解析は未対応）
- **プレイ画面**: 上下左右4レーンにノーツが上から降ってきて、判定ラインに重なるタイミングでレーンをタップ／対応キーを押す一般的な音ゲー形式
- **打鍵音・ヒット演出**: タップ成功時に WebAudio で合成した効果音（PERFECT / GOOD / MISS で音程が変化。音声ファイル不要）が鳴り、
  判定ラインでバーストとレーン発光が起きる
- **難易度**: EASY / NORMAL / HARD で判定ウィンドウ・ノーツ間隔・休符の量が変化
- **熱量ゲージ / FEVER TIME**: PERFECT / GOOD で上昇、MISS で減少。100% 到達で **FEVER TIME**（9秒間）に突入し、
  スコア2倍・ノーツが金色・画面と判定ラインが発光する。フィーバー中はゲージが残り時間のカウントダウンになり、
  ミスしてもフィーバーは中断されない。終了すると熱量20%から再スタート
- **マスコット表示**: 左に判定リアクション枠、右に全身ダンスキャラ枠を常時表示。右のダンスは判定に関係なく曲のBPMに合わせて6ポーズを巡回し続け、左には PERFECT / GOOD / MISS のたびに表情がポップして消える（`assets/mascot/`）
- **コスチュームチェンジ**: 1コンボ15以上つながると私服から `assets/mascot/idol/` のアイドル衣装に切り替わり、以降ミスしても曲の終わりまでその衣装のまま
- **カットイン演出**: 1コンボ30到達、または LIMIT BREAK 発生時に、アイドル衣装の演出イラストが左の反応枠に重なる形でランダムに表示される
- **リザルト演出**: ランク（S〜D）に応じてリザルト画面のまこの表情/ポーズが変化する（S: 演出カット / A: アイドル衣装 / B: 私服で笑顔 / C: 私服で通常 / D: 泣き顔）

## 既知の制約 / 今後の改良候補

- 譜面は BPM ベースの機械生成のため、実際の楽曲のビートとは完全には一致しません（将来的に Web Audio API でのオンセット検出に置き換え予定）
- 難易度による譜面パターンの作り込み（同時押し・パターン生成など）は未実装
